# thefit.style

One-page site for The Fit — used for affiliate-network applications (live
property + privacy policy + affiliate disclosure) and the launch waitlist.

Deployed via GitHub Pages. `CNAME` points the custom domain `thefit.style`;
DNS lives at the registrar (A records → GitHub Pages IPs, or CNAME
`ritumbhara.github.io` on `www`).

The app itself lives in the private `the-fit` repo.
